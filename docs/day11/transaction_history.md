# Transaction History

## User Story

**As a customer,**  
I want to view my transactions in one place,  
so that I can understand where my money is coming from and where it is going.

## Requirements

- Customers should be able to view transactions for their selected account.
- The transaction history should display relevant transaction details.
- The customer should be able to identify debits and credits.
- Transaction status should be distinguishable, including `POSTED`, `PENDING`, `FAILED`, and `REVERSED`.
- The experience should support searching/filtering if included in the product scope.

## Clarifications

- Should transaction history cover one selected account or all accounts?
- Which transaction fields should be displayed?
- Should pending and reversed transactions be shown?
- What should be displayed when there are no transactions?
- What search/filter criteria should be supported?
